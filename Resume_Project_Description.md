# UCI Adult Census Income Clustering - Resume Project Description

## Project Title: 
**UCI Adult Census Income: Unsupervised Machine Learning for Demographic Segmentation**

## Project Bullets for Resume:

• **Designed and implemented unsupervised machine learning pipeline** on UCI Adult Census dataset (48,842 records) to discover hidden demographic and socio-economic clusters in U.S. population data using Python, pandas, and scikit-learn

• **Applied advanced clustering techniques** including HDBSCAN and autoencoder-based clustering to identify 5 distinct population segments, achieving silhouette score of 0.915 and revealing meaningful patterns in socio-economic data

• **Engineered comprehensive data preprocessing pipeline** handling mixed categorical/numerical features, missing values, and outliers using advanced imputation techniques and feature scaling methodologies

• **Developed deep learning autoencoder architecture** using TensorFlow/Keras for dimensionality reduction and latent representation learning, enabling discovery of finer demographic subgroups beyond traditional clustering

• **Implemented multiple dimensionality reduction techniques** (UMAP, PCA) for high-dimensional data visualization and feature space exploration, reducing computational complexity while preserving cluster structure

• **Created interactive data visualization dashboard** using Plotly and Seaborn for cluster profiling and exploratory data analysis, enabling stakeholders to understand demographic patterns and anomalies

• **Built end-to-end MLOps workflow** following industry best practices with modular code structure, version control, automated testing, and reproducible environment setup using virtual environments and requirements management

• **Deployed machine learning model** as interactive web application using modern deployment practices, demonstrating full-stack data science capabilities from research to production
